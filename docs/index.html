instinct_muse

A personal AI agent you can run yourself. The agent works inside a sandbox. Your credentials and network access stay outside it.

View on GitHub Quick start

How it works

Gateway

FastAPI app with web chat over WebSocket. Runs the agent loop and keeps state in Postgres.

Sandbox

Code the agent runs goes into a locked-down container: non-root, no capabilities, no direct internet.

Credential broker

The agent only sees surrogate tokens. Real OAuth tokens never enter the sandbox.

Egress gate

Every outbound request is checked against an allowlist. Real tokens are swapped in at the last step.

Browser worker

Headless Chromium through Playwright. The agent reads accessibility-tree snapshots, not raw HTML.

Model

OpenCode Zen by default, behind a small provider interface so you can swap models.

Quick start

git clone https://github.com/Lesly-umgc/instinct_muse.git
cd instinct_muse
cp .env.example .env   # add OPENCODE_API_KEY
docker compose up --build

Then connect a WebSocket client to ws://localhost:8000/ws/chat.
