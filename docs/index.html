instinct_muse

A personal AI agent with a real desktop UI. It detects the agent CLIs already on your Mac and rides their logins - no API key to configure. You pick the engine and model per chat; the sandbox, credential broker and egress gate keep tools on a leash.

View on GitHub Quick start

How it works

Mac app

Tauri + React interface: Chat, Feed, Ideas, Goals and Library. Streaming replies and inline Allow / Deny approval cards.

App service

FastAPI + SQLite own conversations, memory, goals, approvals and scheduling - independent of the engine, so engines stay swappable.

Sandbox

Code the agent runs goes into a locked-down container: non-root, no capabilities, no direct internet.

Credential broker

The agent only sees surrogate tokens. Real OAuth tokens never enter the sandbox.

Egress gate

Every outbound request is checked against an allowlist. Real tokens are swapped in at the last step.

Browser worker

Headless Chromium through Playwright. The agent reads accessibility-tree snapshots, not raw HTML.

Any engine

OpenCode first, driven through its local server on your existing login. Codex and direct API keys plug into the same adapter interface.

Quick start

git clone https://github.com/Lesly-umgc/instinct_muse.git
cd instinct_muse
pip install -e .[dev]
cd ui && npm install && npm run build && cd ..
uvicorn app.main:app --reload
# open http://127.0.0.1:8000

With the OpenCode CLI installed and logged in, the app detects it and spawns its server - no API key needed. A direct OpenCode Zen API key also works as a fallback engine. Server deploy with Docker Compose is in the README.

Roadmap

  1. Phase 0: OpenCode engine spike: streaming, auth, cancel/resume, approval events
  2. Phase 1 (current): app service + SQLite, engine adapters, CLI detection, React UI (Chat / Feed / Ideas / Goals / Library), Tauri scaffold
  3. Phase 2: memory, goals, durable scheduling, feed generation, connectors via the broker
  4. Phase 3: Mac polish: quick-chat shortcut, dictation, menu bar, signed installer
  5. Phase 4: remote worker for jobs while the Mac sleeps
